# SwiftFind

SwiftFind 是一个 Windows 快速启动器：按一次快捷键，即可搜索文件、应用、系统设置、浏览器书签、剪贴板历史和已打开的窗口。它会根据你的选择调整排序，配置和数据都保存在本机。

完整说明请见 [中文使用手册](docs/使用手册.md)。

## 主要功能

- 通过 **Everything** 快速搜索文件和文件夹；也支持路径浏览、最近文件和文件对话框跳转。
- 搜索开始菜单/商店应用、Windows 设置、浏览器书签、计算结果、网页和自定义命令。
- 直接输入窗口标题（如 `微信`）切换到已打开窗口。
- 输入 `kill 名字` 查找并结束进程；执行前必须再按一次 Enter 确认。
- 保存文本和图片剪贴板历史；支持来源过滤、置顶、自动清理、隐私标记和“忽略程序”名单。
- 对文件或文件夹按 `Shift+F10` / `Alt+Enter` 打开资源管理器原生右键菜单。
- 支持中文、拼音和拼音首字母搜索；会学习常用选择，但可随时清除学习记录。

## 安装与运行

### 直接使用

从 GitHub Actions 的构建产物下载 `swiftfind.exe`，放到可写目录后运行。首次运行会在程序同目录创建 `data`；若该目录不可写，则自动使用 `%APPDATA%\SwiftFind`。

### 从源码构建

要求：Windows、Rust stable（MSVC 工具链）。Everything 是推荐依赖：没有它时，应用、设置、命令等本地功能仍可用，但全盘文件搜索不可用。

```powershell
cargo build --release
```

产物位于 `target\release\swiftfind.exe`。开发时可运行：

```powershell
cargo test
cargo run
```

## 30 秒上手

1. 运行 SwiftFind，按 `Alt+Space` 呼出或隐藏搜索框。
2. 输入应用、文件、设置或窗口标题，使用方向键选择，按 Enter 执行。
3. 输入 `cb` 打开剪贴板历史；输入 `recent` 查看最近文件。
4. 在文件结果上按 `Shift+F10` 打开原生右键菜单；按 `Alt+1..9` 直接执行前九项。
5. 按 `Ctrl+,` 打开设置，配置 Everything、快捷键、搜索来源、剪贴板和排除目录。

## 常用输入

| 输入 | 作用 |
|---|---|
| `微信` | 搜索应用、文件和标题含“微信”的窗口；Enter 可切换窗口 |
| `f 报告` | 仅搜索文件和文件夹 |
| `a chrome` | 仅搜索应用 |
| `s 防火墙` | 仅搜索 Windows 设置 |
| `b github` | 仅搜索浏览器书签 |
| `C:\Users\` | 浏览目录；继续输入可过滤条目 |
| `recent 预算` | 搜索 Windows 最近文件 |
| `cb chrome img` | 搜索来自 Chrome 的图片剪贴板记录 |
| `kill notepad` | 查找记事本进程，连续按两次 Enter 结束 |
| `g rust ownership` | 用 Google 搜索；也可用 `bd`、`bing`、`gh`、`yt`、`zh` |
| `2*(3+4)` | 计算并复制结果 |
| `> ipconfig /all` | 在命令提示符中执行一次临时命令 |

## 快捷键速查

| 快捷键 | 作用 |
|---|---|
| `Alt+Space` | 呼出/隐藏 SwiftFind（默认，可改） |
| `Ctrl+Alt+V` | 直接打开剪贴板历史（默认，可改） |
| `↑` / `↓`、`Ctrl+K` / `Ctrl+J` | 选择结果 |
| `Enter` | 打开、执行或粘贴 |
| `Ctrl+Enter` | 以管理员身份运行可提升的项目 |
| `Shift+Enter` | 打开所在文件夹；在剪贴板历史中仅复制 |
| `Alt+1..9` | 直接执行第 1..9 个结果 |
| `Shift+F10` / `Alt+Enter` | 显示文件或文件夹的资源管理器原生右键菜单 |
| `Ctrl+C` | 复制当前文件/文件夹，可在资源管理器中粘贴 |
| `Ctrl+Shift+C` | 复制路径 |
| `Ctrl+T` | 在所选文件或文件夹所在目录打开终端 |
| `Ctrl+D` | 排除当前文件或文件夹 |
| `Ctrl+Delete` | 清除当前项目的学习记录；剪贴板项则删除该记录 |
| `Ctrl+P` | 置顶/取消置顶剪贴板项 |
| `Alt+Delete` | 删除当前条件匹配的全部未置顶剪贴板项（需二次确认） |
| `Tab` / `→` | 在路径浏览中补全所选项 |
| `Alt+←` | 在路径浏览中返回上级目录 |
| `Ctrl+,` | 打开设置 |
| `Esc` | 清空输入或隐藏窗口 |

## 数据与隐私

所有数据只保存在本机：`config.json` 保存设置，`learn.json` 保存排序学习记录，`clipboard.redb` 保存剪贴板历史。可在设置中关闭剪贴板记录、设置容量/保留时间、关闭图片记录，或填写要忽略的程序名（如 `keepass.exe`）。带有 Windows“不要记录”标记的剪贴板内容会自动跳过。
