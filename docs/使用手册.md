# SwiftFind 使用手册

SwiftFind 是 Windows 的本地快速启动器。它以一个搜索框统一访问文件、应用、设置、书签、窗口、剪贴板和命令。除网页搜索外，索引、学习记录和剪贴板数据都只留在本机。

## 开始前的设置

运行 `swiftfind.exe` 后，默认按 `Alt+Space` 呼出窗口；再次按下隐藏。通知区域图标左键也可切换窗口。使用 `--background` 参数启动时，程序先在后台运行。

按 `Ctrl+,` 进入设置，可配置快捷键、Everything、主题、失焦隐藏、游戏模式、搜索来源、剪贴板和排除目录。窗口可从大多数空白处、结果行或标题区域拖动，位置会自动记住。

### Everything（推荐）

Everything 用于全盘文件搜索：

1. 安装后可将设置中的路径留空，SwiftFind 会在常见目录和 `PATH` 中检测。
2. 未检测到时，填写 `Everything.exe` 完整路径并点击“应用”。
3. Everything 未运行时，SwiftFind 会尝试用 `-startup` 启动它。

没有 Everything 时，应用、系统设置、书签、路径浏览、最近文件、窗口和剪贴板等功能仍可用；只有全盘文件搜索不可用。

## 基本操作与搜索范围

输入会实时更新结果。`↑` / `↓` 或 `Ctrl+K` / `Ctrl+J` 选择结果；Enter 打开、执行或粘贴。`Alt+1..9` 可直接执行第 1 至第 9 个结果，`Esc` 清空输入或隐藏窗口。

默认搜索会混合多个来源。若只想搜一种来源，可在输入开头加前缀和空格：

| 前缀 | 示例 | 作用 |
|---|---|---|
| `f ` | `f 合同` | 仅文件和文件夹 |
| `a ` | `a chrome` | 仅应用 |
| `s ` | `s 显示器` | 仅 Windows 设置 |
| `b ` | `b 工作` | 仅浏览器书签 |

如果你定义了同名的命令或网页搜索触发词，那个自定义触发词优先。右键任何结果可打开 SwiftFind 的操作菜单。

## 文件、路径和最近文件

### 全盘文件搜索

直接输入名称、路径片段或 Everything 语法：

```text
ext:pdf 报告
size:>100mb
*.log
path:D:\work foo
```

设置中的“排除目录”会从 SwiftFind 和 Everything 结果同时隐藏，适合回收站、构建缓存或私有目录。

### 路径浏览

以下输入会直接浏览目录，而不是调用 Everything：

```text
C:\Users\
~\Documents
%appdata%
```

`~` 是用户目录，`%变量名%` 会展开环境变量。继续输入可过滤条目，文件夹优先。`Tab` 或 `→` 补全选择，`Alt+←` 回到上级目录，Enter 打开。默认隐藏系统/隐藏项；用 `.` 或 `$` 开头过滤时显示它们。网络共享路径（如 `\\server\share`）不支持。

### 最近文件和文件对话框

输入 `recent` 或 `最近` 查看 Windows 最近文件；如 `recent 预算`、`最近 报告` 可继续筛选。删除的文件会自动隐藏。

在“打开”或“另存为”标准文件对话框前台时呼出 SwiftFind，选择文件夹/文件按 Enter，原对话框会跳转到其目录；选中文件时会一并填入文件名。

## 应用、设置、书签与网页

SwiftFind 从开始菜单与 Microsoft Store 应用建立索引，支持中文、英文、全拼和拼音首字母：例如 `wx`、`weixin` 可找到微信。Windows 设置包含大量 `ms-settings:`、控制面板和系统管理入口，也支持拼音首字母，如 `hjbl` 查找环境变量。

会读取 Chrome、Edge、Brave、Vivaldi 的书签，按标题、网址、文件夹和拼音搜索；Firefox 目前不支持。网页搜索默认如下：

| 输入 | 网站 |
|---|---|
| `g 关键词` | Google |
| `bd 关键词` | 百度 |
| `bing 关键词` | Bing |
| `gh 关键词` | GitHub |
| `yt 关键词` | YouTube |
| `zh 关键词` | 知乎 |

可在 `config.json` 的 `web_searches` 中添加站点，URL 模板中使用 `{q}` 代表关键词。

## 窗口切换与进程管理

### 按标题切换窗口

普通搜索同时包含当前已打开的顶层窗口。输入标题即可切换，例如：

```text
微信
项目 - Visual Studio Code
```

选中窗口结果按 Enter，SwiftFind 会恢复最小化窗口并切到前台。副标题显示进程名，便于区分同名窗口。

### 快速结束进程

输入 `kill`、空格和进程名称：

```text
kill notepad
kill chrome
```

结果显示进程名和 PID。第一次 Enter 只要求确认；五秒内再次 Enter 才会结束。请先保存工作。受保护或更高权限的进程可能无法结束。

## 文件操作与原生右键菜单

选中文件或文件夹时：

| 快捷键 | 作用 |
|---|---|
| Enter | 打开 |
| Shift+Enter | 在资源管理器中定位或打开所在文件夹 |
| Shift+F10 / Alt+Enter | 显示资源管理器原生右键菜单 |
| Ctrl+C | 复制文件对象，可在资源管理器粘贴 |
| Ctrl+Shift+C | 复制完整路径文本 |
| Ctrl+T | 在所在目录打开终端，优先 Windows Terminal |
| Ctrl+D | 将该项加入排除目录 |

原生右键菜单会保留重命名、删除到回收站、属性、打开方式、压缩、发送到，以及 7-Zip 等已安装扩展提供的项目。

## 剪贴板历史与隐私

### 打开和搜索

默认 `Ctrl+Alt+V` 直接打开历史，也可输入 `cb` 或 `clip`。在其后追加关键词可按内容或来源程序查找：

```text
cb chrome
cb 项目地址
cb chrome img
cb text
cb pin
```

`img` 仅图片，`text` 仅文本，`pin` 仅置顶项，可组合。Enter 粘贴到呼出 SwiftFind 前的窗口；`Shift+Enter` 只复制。`Ctrl+P` 置顶/取消置顶，`Ctrl+Delete` 删除当前条目，`Alt+Delete` 删除筛选到的全部未置顶项目（需二次确认）。重复内容不会新增，只会移到最前。

### 隐私保护

带有 Windows“不要记录”剪贴板标记的内容会自动跳过。还可在设置的“忽略这些程序”中填写 exe 名，使用逗号、分号或换行分隔：

```text
keepass.exe, 1password.exe, bitwarden.exe
```

设置可关闭历史、关闭图片记录，或限制最大记录数、保留天数与图片总容量。仅纯文本和图片会被记录；富文本和资源管理器复制的文件列表不写入历史。

## 命令、计算器和文本片段

### 命令

内置命令包括 `cmd`、`ps`、`wt`、`hosts`、`lock`、`sleep`、`shutdown`、`restart`、`logoff`、`flushdns`、`ip`、`ping`、`hibernate`、`shot`、`darkmode`、`emptybin`、`restartexplorer`。危险命令需要连续按两次 Enter。

输入 `>` 可执行一次临时命令：

```text
> ipconfig /all
> git status
```

命令在命令提示符中运行；`Ctrl+Enter` 可请求管理员权限。临时命令不参与排序学习。

### 计算与文本片段

输入 `2*(3+4)`、`1.5/3` 等算式会显示计算结果；Enter 复制结果。可在 `config.json` 的 `snippets` 定义片段：

```json
{ "name": "公司邮箱", "text": "me@example.com", "keywords": ["mail", "邮箱"] }
```

片段 Enter 后会粘贴到之前的窗口。支持 `{date}`、`{time}`、`{datetime}`、`{year}`、`{month}`、`{day}`；`{{` 与 `}}` 输出字面大括号。

## 排序学习、设置和数据

SwiftFind 记录“输入内容 + 所选项目”，相似输入下常选项目会靠前；长期不用的记录会衰减。若排序不合适，选中项目按 `Ctrl+Delete` 清除学习记录。文件/文件夹不想出现时按 `Ctrl+D`。

设置中的主要选项：

- Everything 路径、呼出快捷键、剪贴板快捷键。
- 深浅主题、失焦隐藏、游戏模式、窗口位置和空输入时常用项目。
- 文件、应用、书签、Windows 设置等搜索来源。
- 剪贴板开关、容量、保留时间、图片容量和忽略程序名单。
- 排除目录与重新加载配置。

数据目录优先级：`SWIFTFIND_DATA` 环境变量指定的目录、程序同目录 `data`、不可写时 `%APPDATA%\SwiftFind`。常见文件：

| 文件 | 内容 |
|---|---|
| `config.json` | 设置、自定义命令、文本片段、网页搜索 |
| `learn.json` | 排序学习记录 |
| `clipboard.redb` | 剪贴板历史 |
| `apps_cache.json` | 应用索引缓存 |
| `swiftfind.log` | 运行日志 |

自定义命令示例：

```json
{
  "name": "project",
  "title": "打开项目目录",
  "program": "explorer.exe",
  "args": "D:\\work\\project",
  "admin": false,
  "confirm": false,
  "keywords": ["项目", "work"]
}
```

`name` 为触发词；参数中的 `{q}` 替换为触发词后的输入。手动修改 `config.json` 后，请在设置中重新加载配置。配置损坏时会被保留为 `config.json.bad`，不会被静默覆盖。

## 技巧与排障

### 推荐工作流

- 用 `Alt+Space` 搜索应用、文件或窗口，减少在任务栏和资源管理器间切换。
- 用 `cb` 找回刚复制的命令、链接或截图；重要记录按 `Ctrl+P`。
- 在保存对话框中用路径浏览定位深层目录，再 Enter 跳转。
- 文件结果上优先按 `Shift+F10`，直接使用资源管理器及第三方扩展的操作。
- 连续选择常用项目几次即可提高排序，无需手动固定。

### 常见问题

| 现象 | 处理方法 |
|---|---|
| 搜不到全盘文件 | 确认 Everything 已安装、运行且路径正确；检查排除目录 |
| 全局快捷键无反应 | 在设置中重新录制；组合键可能被其他程序占用 |
| 窗口无法切换 | 窗口可能已关闭、被权限隔离，或不是普通顶层窗口 |
| 进程无法结束 | 受保护或更高权限进程可能拒绝结束 |
| 剪贴板未记录 | 检查历史开关、忽略程序名单及“不要记录”标记 |
| 无界面或启动失败 | 查看 `data\swiftfind.log`；远程桌面、虚拟机或旧驱动可能缺少 OpenGL 支持 |

反馈问题时请附上 Windows 版本、SwiftFind 版本、复现步骤和 `swiftfind.log`。
